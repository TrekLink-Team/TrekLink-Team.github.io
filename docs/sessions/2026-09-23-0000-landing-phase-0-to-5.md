## Goal

Stand up the landing repository, then build the site itself far enough that the
deploy pipeline is proven before Review 1 on 1 October.

## What shipped

**Phase 0.** `TrekLink-Team/TrekLink-Team.github.io` created public, `main` and
`dev` pushed, Pages set to `build_type: workflow`, the repository registered in
the canonical `AGENTS.md` across all five copies.

**Phases 1 to 5.** Astro 7 with Tailwind 4 and TypeScript strict. Three real
HTML routes. A locale system with English as the reference and Vietnamese
falling back visibly. Six components composed once in `LandingPage.astro`. Four
islands, each upgrading markup that already works. Twenty unit tests over the
health check and the locale resolver. The Pages deploy workflow. Cloudflare Web
Analytics.

Published output: about 204 KB including self-hosted fonts.

## Decisions taken here

**Visual direction: Timberline.** Three directions were built in real CSS and
compared side by side, one close to each reference site the leader supplied and
one written against question 15 instead. The leader chose the third and
instructed that the reference sites be treated as samples rather than as
layouts to copy. Recorded in `specs/landing/design.md` §5.1 with the resolved
token values and their computed contrast ratios.

**Analytics: Cloudflare Web Analytics.** GoatCounter lost on licensing, because
its free tier is for non-commercial use and a graded university project sits
ambiguously against that clause. Plausible is paid. Self-hosting Umami would
mean running a backend, which REQ-UBI-01 forbids. Closes Q2.

**Hero and problem copy approved as final.** The drafted wording stands rather
than being replaced. Closes Q3.

**Branch protection applied to all four code repositories.** None of the three
existing repositories had any, despite convention 07 §7 requiring it.
`enforce_admins` is off, deliberately and with the reason recorded in
convention 07, because the organisation has no collaborators who could supply
the required approval and a hard admin gate would leave every pull request
unmergeable.

## Findings worth not re-deriving

**The `capstone` auto-sync timer does not exist.** No systemd timer, no cron
entry. D-022 describes a timer that was never scheduled on this machine, which
is why the em dash sweep sat uncommitted for a day. Commits there are manual
until somebody schedules it.

**A squash merge takes only what is on the branch at that instant.** Pull
requests #2 and #3 were merged while commits were still being pushed to their
branches, stranding work on a deleted branch twice. Both were recovered by
rebasing onto `dev` and reopening, but it cost a round trip each time.

**Astro's dev server can break on hot restart after a config change** and start
serving 404 for every route while the production build stays correct. Restart
the server rather than debugging the routes.

**`gh pr edit --title` fails** on a Projects-classic GraphQL deprecation.
`gh api -X PATCH .../pulls/N -f title=...` works.

## Things that were built and then removed

**Graded raw photographs.** The leader's raw shots were cropped to the layout's
aspect ratios and given a common warm grade to reconcile three disagreeing
backgrounds. The leader rejected the result, correctly: a raw workshop
photograph does not belong on a landing page whatever is done to it in
software. All four slots returned to typographic placeholders and processed
visuals are coming from the leader instead. The revert was a four-line edit
because `src/lib/media.ts` already centralised the slots.

**A fabricated range figure.** An early mockup carried a "12 km mesh range"
stat. That number is measured nowhere in this project. It was removed before
any of it reached a commit on the site, and every remaining hardware claim
traces to `_docs/00-project-context/04-firmware-ground-truth.md` §5.

## Spec corrections made in the same pass

- `ProductLines` became `NodeLines`. The hardware answer was one node in three
  versions, so there is no plural product line.
- `analyticsId` became `analyticsToken`, and an empty value emits no tag at all.
- Design §5.1 replaced six placeholder token rows with the resolved set.
- Design §5.3 dropped the planned shadcn glass registry. Two utility classes
  turned out smaller than re-theming someone else's component.
- The issue-template `config.yml` in `treklink-docs` had three dead references:
  a repository name that does not exist, a register path missing its `_docs/`
  segment, and a claim that D-005 was open when it closed on 2026-09-16.

## Open

Nine tasks, all in phases 6 and 7: the processed visuals, the remaining
Vietnamese translation, axe and Lighthouse in CI, the manual keyboard pass,
both availability rehearsals against the deployed site, and the phase 7.6 spec
audit.

`site.config.ts` still carries placeholder values for `operationsUrl` and
`healthEndpoint` under Q1, which stays open until the operations backend is
deployed. That is by design: the health check treats an unreachable endpoint as
unavailable, which is the REQ-EVT-04 path, so the placeholder is a working
state rather than a broken one.
